Question 1

Take a number N and print numbers from N down to 1.

Algorithm:

1. Start.
2. Prompt and input positive integer N.
3. Check N: If N < 1, display error message and go to step 6.
4. start loop as variable i = N.
5. Repeat while i >= 1:
Output the value of i.
 	Decrement i by 1 (i = i - 1).
6. End.






Pseudo Code:

	
begin

read n

if n < 1then

print "error: n must be greater than or equal to 1"

else

for i from n down to 1 do

print i

end for

end if

end.
